# 応用情報 合格ノート

応用情報技術者試験（AP）の学習用Webサイトです。HTML / CSS / JavaScript だけで動きます（ビルド不要・ライブラリ不要）。

## 使い方

1. このリポジトリをクローン（またはZIPでダウンロード）
2. `index.html` をブラウザで開く

学習記録（学習済み単元・テストの最高点・間違えた問題）は、ブラウザの localStorage に保存されます。

### スマホで使う

公開URL：https://itoyoshiki225.github.io/ap-study/ （GitHub Pages を有効にした後）

- **iPhone（Safari）**：共有ボタン → 「ホーム画面に追加」
- **Android（Chrome）**：メニュー（︙）→ 「ホーム画面に追加」／「アプリをインストール」

ホーム画面から開くとアプリのように全画面で使えます。一度開いたページはオフラインでも表示できます（電車の中でも学習可能）。スマホでは画面下のタブ（ホーム／単元／模試／科目B／復習）で移動できます。

## 中身

| 画面 | 内容 |
|---|---|
| ホーム | 試験日までのカウントダウン、進み具合、次にやること |
| 応用情報とは・試験日 | 試験の概要、令和8年度の日程、出題形式、2027年度からの新制度 |
| 学習ロードマップ | 後期試験に向けた週ごとの計画、科目Bの選択分野のおすすめ |
| 単元一覧／単元ページ | 全20単元。解説・用語まとめ・確認クイズ（ランダム5問） |
| 単元テスト | 単元ごとの全問テスト（80%以上で合格ライン、学習済みに自動登録） |
| 模擬試験 | 本番の分野配分で20／40／80問、時間制限つき、分野別の正答率 |
| 科目B対策 | 11分野の解き方と、オリジナル事例での記述演習（解答例つき） |
| 間違えた問題 | 間違えた問題だけをまとめて解き直し |
| 学習記録 | 単元ごとの状態と履歴 |

選択肢の並び順は毎回シャッフルされます。

## ファイル構成

```
index.html
css/style.css
js/app.js                 画面とクイズの処理
js/data/exam.js           試験日程・形式（日程が変わったらここを更新）
js/data/units-tech1.js    基礎理論 / アルゴリズム / CPU / システム構成要素
js/data/units-tech2.js    OS / ハードウェア・UI / データベース / ネットワーク
js/data/units-tech3.js    セキュリティ①② / システム開発 / 開発管理
js/data/units-mgmt.js     プロジェクトマネジメント / サービスマネジメント / 監査
js/data/units-strat.js    システム戦略 / 経営戦略 / 技術戦略 / 企業活動 / 法務
js/data/kamoku-b.js       科目B 11分野
```

## 問題を追加するには

`js/data/units-*.js` の各単元の `quiz` 配列に追加します。

```js
{ q: "問題文", c: ["選択肢ア", "選択肢イ", "選択肢ウ", "選択肢エ"], a: 0, e: "解説（HTML可）" }
```

`a` は正解の番号（0＝ア 〜 3＝エ）です。

## 注意

- 収録している問題は、すべてオリジナルの参考問題です。本番レベルの演習には [IPAの過去問題](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html) も使ってください。
- 試験日程は 2026年11月22日時点の [IPA公式情報](https://www.ipa.go.jp/shiken/2026/ap_koudo_sc_kikan.html) に基づいています。申込前に必ず公式サイトで確認してください。
